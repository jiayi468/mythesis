# 中期答辩补充实验验证报告

更新日期：2026-10-16

## 结论摘要

1. 扩展协议共 314 张图，训练/验证路径交集为 0；B1、B2 各完成 3 个训练种子。
2. B0 合并 Pixel AP 为 `0.0241`，原始 CLIP Patch 语义不足以直接定位工业缺陷。
3. B1/B2 合并 Pixel AP 分别为 `0.7924±0.0191` 与 `0.7924±0.0070`，几乎相同；B2 的 Image AUROC 为 `0.9012±0.0026`，高于 B1 的 `0.8801±0.0105`。文本原型只获得图像级正向证据，尚无稳定定位优势。
4. max 聚合在同一验证集上的合并 Image AUROC 均值为 `0.9245`，高于固定 0.995 分位数，但只能作为诊断，不能作为无偏模型选择。
5. Full+Oracle 的三种子合并逐图 Pixel AP 比 Full 平均提高 `0.0430`，`pill` 和 `screw` 均为 3/3 个种子正向，路线决策为 **GO**。该结果使用 GT ROI，不是可部署结果。
6. 固定张量 ONNX CPU↔WebGPU 分数误差为 `8.69e-07`，后端一致；Canvas 图像路径分数误差为 `0.018327`，预处理一致性未通过。

## 结论边界

- 当前实验仍是 MVTec AD 两类源域监督开发验证，不是官方无监督协议或跨数据集零样本结果。
- B2 的图像级优势不能外推为跨数据集优势。
- Oracle ROI 只证明局部放大存在上界价值；下一步仍需验证自动候选的 Region Recall@K。
- 浏览器端只能确认固定张量后端一致，不能声称完整图像链路一致或 WebGPU 加速。

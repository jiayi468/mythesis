## 4. 最小实验设计：三天内真正需要跑什么

### 4.1 P1：基础异常响应（优先级最高）

**输入：** MVTec AD 源域开发子集（源域训练/验证不重叠）。  
**处理：** 冻结 CLIP、固定 Prompt、最小 Patch 异常头。  
**输出：** `14×14` 异常图，映射到原图；图像级异常分数。

保留四种证据：

1. 数据与掩膜检查图；
2. 模型输出张量形状与推理日志；
3. 训练 Loss 变化（若已训练）；
4. 验证图像的“原图—GT 掩膜—预测热力图”拼图；可选初步 AUROC/AP。

**最低判断标准：** 模型产生真实且可解释的空间响应；不能仅靠一张效果好的图片判断整体模型有效。若源域验证太少，定量结果写为“探索性/小样本初测”，不宣称统计可靠。

### 4.2 P2：ONNX / WebGPU 基础兼容（第二优先）

固定 `224×224、B=1` 与同一组权重、同一预处理，记录：

| 检查项 | 结果记录方式 |
|---|---|
| PyTorch 输出 | 保存 `anomaly_map`、`image_score` |
| ONNX CPU 输出 | 记录导出/运行成功与否，数值误差 |
| WebGPU 输出 | 明确执行后端，是否真的完成前向 |
| 一致性 | 同一输入的异常图差异、分数差异；有多张样本再比较排序 |
| 性能 | 模型加载、首次推理、预热后推理；注明测量轮数与设备 |
| 失败时 | 具体日志、已尝试措施、预期回退办法 |

**禁忌：** 不把 CPU/WASM 回退结果标为 WebGPU；不把一次偶然成功称为稳定运行。

### 4.3 P3：Oracle ROI（仅有余力时）

- 用**源域验证掩膜**定位真实缺陷，选 1 个从**原始高分辨率图像**裁出的 ROI；缩放到 224 后用同一模型推理。
- 将 ROI 热力图回投原图，与全图上采样异常图取逐像素最大值；最终图像分数继续用 `99.5%` 分位数。
- 可视化比较 `224 全图` 与 `224+Oracle 1 ROI`；如资源允许，增加 `Top-1 ROI`，检查实际候选是否选中缺陷。
- **说明：** Oracle 只为判断局部观察的理论价值，不作为正式零样本推理方法，也不能参与目标域最终评分。

### 4.4 P4：固定 K 延迟（只记录已测）

有 WebGPU 稳定运行后，先测 `K=0`；再依次尝试 `K=1/2/4`。若未实现 ROI，只报告全图 `B=1` 的初始化与推理时延。

实验表模板（所有数值必须实测，未测留空）：

| 条件 | 源域 Image AUROC | 源域 Pixel AP | WebGPU 端到端 P50 | WebGPU 端到端 P95 | 备注 |
|---|---:|---:|---:|---:|---|
| 224 全图 | 待测 | 待测 | 待测 | 待测 | 基础基线 |
| 224+Oracle 1 ROI | 待测 | 待测 | 待测 | 待测 | 分析上界，不是正式方法 |
| 224+Top-1 ROI | 待测 | 待测 | 待测 | 待测 | 有余力再做 |

## 6. 答辩容易被问到的 8 个问题

| 问题 | 回答要点 |
|---|---|
| 1. 为什么一定要 WebGPU，PyTorch 本地部署不行吗？ | 本地原生部署当然可行；WebGPU 重点是浏览器跨平台、免专用部署与本地隐私，以及受限环境的精度—开销实测，而非声称比本地 CUDA 更快。 |
| 2. 为什么选 CLIP ViT-B/16？ | 生态成熟、有图文对齐能力、规模相对可控，冻结主干便于控制训练/导出复杂度；无法运行则记录后降级 ViT-B/32。 |
| 3. 你的创新在哪里？ | 不是“首次粗到细”，而是微小缺陷候选保持学习与设备实测代价驱动的 ROI 计算分配；创新性要靠后续消融与对照成立。 |
| 4. 用了源域异常掩膜，还能说零样本吗？ | 要明确是“目标域零训练/零调参/零阈值校准”的跨数据集设定，而非完全不使用任何异常监督。 |
| 5. 为什么低分辨率粗图能发现微小缺陷？ | 这是待检验假设，不能保证；先通过 Oracle 与真实 Top-K 两层实验区分“局部有价值”和“候选找得到”。 |
| 6. 如何证明 ROI 不是简单用更多计算换精度？ | 固定 K、随机/网格、Top-K+NMS、简单动态阈值、无设备感知动态 K 等对照；最终比较实际 Accuracy–Latency 曲线。 |
| 7. WebGPU 跑不起来怎么办？ | 先检查 ONNX 算子/固定形状/后端；独显优先验证，必要时减小骨干；中期如实汇报兼容边界，不假报运行。 |
| 8. 如果 Oracle ROI 没有提升怎么办？ | 停止复杂粗到细调度，转向轻量缺陷保持与全局—局部尺度一致性方案；仍需独立消融验证创新性。 |
